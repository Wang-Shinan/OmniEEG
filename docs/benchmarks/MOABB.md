# MOABB

版本：2026-11-13，基于已读取公开来源。

## 要解决的问题与评价对象

参考一致预处理、跨被试/跨会话评价和传统BCI强基线。

## 实验组织

统一数据与算法接口、可复现比较；适用于补充任务特定诊断。

## 与本赛事的关系

不替代赛事协议，也不需要为初赛跑完全部MOABB。

## 阅读与复现检查点

记录数据集与任务定义、被试隔离、预处理、适配方式、调参预算、种子作用、指标及预训练重叠处理。相同数据集名称并不足以保证分数可比。

## 来源

- [MOABB: trustworthy algorithm benchmarking for BCIs（JNE 2018）](https://pubmed.ncbi.nlm.nih.gov/30177583/)。
