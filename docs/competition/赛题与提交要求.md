# OmniEEG Challenge 2026：赛题与提交要求

记录日期：2026-11-13。依据本聊天提供的参赛手册和三张宣讲截图。以下为所提供版本的规则，不代表已经核对官方参赛群最新通知。手册页码指正文页码。

## 比赛希望考察什么

考察EEG基础模型的跨被试、跨数据集和跨任务能力。共7个分赛道，每道2个数据集；主赛道默认覆盖全部分赛道。选择后不能更改。每队2–3人。

## 阶段与交付

- 初赛：规划11月2–15日。提交研究方案PDF和PPT；不要求代码、权重或已完成实验。符合要求的队伍超过64支时，按评分排序晋级（宣讲截图补充）。
- 复赛：规划11月23日至12月6日。公开14个下游数据集，可用公开可下载的预训练权重，开展微调、线性探测或适配器实验；提交代码与权重。
- 决赛：规划12月14–27日。在官方语料与算力下随机初始化训练全新自研基础模型，不得加载公开或私有预训练权重；提交预训练代码、权重和方法报告。
- 12月28日起复现核验，规划2027年1月中旬公布结果。详细节点与概述存在差异，最终以官方通知为准。

复赛、决赛使用共享GPU资源池，不允许自备算力提交结果。参赛代码须可复现。原文见手册第3–6、12页。

## 数据规格

下游数据统一200Hz；此版未披露数据集名称、来源、类别数和标签分布。不能把规格与某个熟悉的数据集自动对应。

- 信号可靠性：58通道×2秒；18通道×2秒。
- 疾病诊断：19通道×2秒；20通道×10秒。
- 睡眠分期：4通道×30秒；6通道×30秒。
- 认知与情绪：30通道×10秒；62通道×10秒。
- 自然刺激解码：两个均为128通道×2秒。
- 运动想象：64通道×4秒；22通道×4秒。
- SSVEP：60通道×1秒；60通道×2秒。

决赛预训练语料为21个OpenNeuro数据集，包含32/64/76/128通道配置，同样200Hz，并已完成与下游评测的被试隔离。下游评测数据与复赛相同。原文见第4–5页。

## 评测

训练/验证/测试按被试8:1:1隔离。三个指定随机种子各重新进行被试划分；按验证集BACC选择权重，测试结果取三次均值。

主指标为平衡准确率，辅助指标为PR-AUC、ROC-AUC和F1。每分赛道两个数据集的BACC等权平均。主赛道累计各分赛道排名积分，不等同于直接平均14个数据集的分数。具体辅助指标实现、种子和接口待后续说明。原文见第6、11–12页。

## 初赛提交

邮箱：challenge@omni-intel.cn。材料为一份PDF和一份.pptx或.ppt；封面标注方案标题、赛道、队伍名称和参赛人员姓名。章节与页数为建议格式，不是硬性限制。

评分：研究动机10；相关工作与研究见解35；方法设计与论证35；实验与消融计划20。没有已完成实验也可得满分；实验计划仍须提交。算力需求需填写但不计分。

方案应解释研究问题、与赛道的关系、方法为何用于EEG、数据来源和复现计划。仅堆技术名词、直接套通用模型而无针对性改进，或使用未披露私有数据，不能通过材料审核。手册第6–10页及宣讲截图为依据。
