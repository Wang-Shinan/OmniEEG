# BIOT：研究问题、架构与训练逻辑

> 版本：2026-11-13 / 论文笔记 v0.1。正文基于已保存原文及公开评测；尚未完成代码逐层核验或本地复现。统一记号见[阅读约定](../process/文档维护与阅读约定.md)。

## 研究出发点

跨数据源的生理信号具有通道数、长度与缺失情况差异。作者把共同建模的基本单位放在单个通道的局部片段上，希望让异构记录可以转为统一的token序列。

## 从输入到输出的架构

每个通道分别切成时间片段，对局部信号进行频域变换和投影，得到biosignal token。向token加入通道embedding和相对时间位置后，把来自不同通道的token组织为长序列。

骨干采用linear Transformer，减少长序列中全注意力的成本。聚合后的表示可连接任务分类器，也可用于自监督学习。

预训练通过对同一信号的子片段/扰动视图构造表示学习信号，涉及对比式学习；原论文还比较有监督预训练和多数据集训练。因此“BIOT成绩”必须附带具体checkpoint来源及训练方式。

论文架构支持异构输入，并不意味着任一已发布checkpoint在任意导联布局上无需适配；二者应分别记录。

## 训练目标与阶段

对比式学习鼓励同一记录的不同视图产生相关表示，再在下游监督任务中适配。需要检查被选checkpoint的通道编码、频域分辨率、缺失通道处理和分类头大小。用它解释REVE临床任务的差距时，应先测试简单频谱特征是否已提供互补信息。

## 实验告诉了我们什么

NeuralBench整体平均排名11.31，但帕金森诊断77.247%对REVE69.340%；说明局部专长可能比总体名次更有借鉴价值。

这些结果的协议和具体源表见[评测证据](../benchmarks/评测证据与可比性.md)。整模型优于另一模型，只能支持该完整设置下的比较；模块作用需要相应消融。

## 局限和仍需核对的问题

公开模型具体montage与适配器会影响结果；临床优势不等于线性attention本身带来优势。不能把BIOT统称为MAE。

实现核对时重点记录：预处理、实际token形状、位置表示、mask与loss的作用位置、checkpoint版本、可训练模块及读出接口。没有核验到的层数、配置或实现差异不补成确定事实。

## 对本项目的启发

对疾病任务增加简单频谱/功率诊断基线；只有持续优于REVE时，才将对应特征接入残差分支。

上述启发是待验证判断。当前研究问题见[REVE改进假设](../research/REVE改进假设.md)，不能把本笔记中的作者模型和我们的改造方案视为同一个模型。
