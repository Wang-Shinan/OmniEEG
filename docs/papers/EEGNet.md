# EEGNet：研究问题、架构与训练逻辑

> 版本：2026-11-13 / 论文笔记 v0.1。正文基于已保存原文及公开评测；尚未完成代码逐层核验或本地复现。统一记号见[阅读约定](../process/文档维护与阅读约定.md)。

## 研究出发点

目标是在数据较少的BCI任务上，用紧凑结构表达常见的频率与空间滤波操作，使同一种网络设计可用于多种范式。它是监督学习基线，不能与预训练收益混为一谈。

## 从输入到输出的架构

把输入表示为 $B\times1\times C\times T$。

1. 时间卷积核沿T轴滑动，对每个通道学习时间滤波响应，产生多个特征图。
2. Depthwise空间卷积在C轴上聚合电极，针对各时间滤波特征学习空间投影，而不是为每对输入输出特征都使用完整卷积。
3. 非线性、归一化、平均池化与dropout压缩和正则化特征。
4. Separable卷积先逐特征图提取时间模式，再通过pointwise卷积组合不同特征图。
5. 最终特征连接分类头。

时间卷积与空间卷积的顺序具有明确意义：先形成频率敏感响应，再学习这些响应在头皮上的组合。其输出通道维压缩方式通常绑定输入C，因此换导联配置时要重新配置网络。

## 训练目标与阶段

通常以任务标签和交叉熵从随机初始化训练，没有默认的通用EEG预训练阶段。应单独记录每任务的输入窗口、池化参数和正则化。作为新局部分支的参照时，需比较其单独训练结果，确认所谓“融合收益”是否真来自REVE与局部特征互补。

## 实验告诉了我们什么

FAME的13任务同表中，EEGNet精神分裂症71.0%对REVE47.2%；NeuralBench也显示部分任务专用网络有优势。该结果不代表EEGNet总体胜过REVE。

这些结果的协议和具体源表见[评测证据](../benchmarks/评测证据与可比性.md)。整模型优于另一模型，只能支持该完整设置下的比较；模块作用需要相应消融。

## 局限和仍需核对的问题

通常需要针对通道数/类别数配置；没有大规模预训练的跨布局能力。小样本和预处理也可能解释优势。

实现核对时重点记录：预处理、实际token形状、位置表示、mask与loss的作用位置、checkpoint版本、可训练模块及读出接口。没有核验到的层数、配置或实现差异不补成确定事实。
