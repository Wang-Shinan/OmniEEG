# ECHO：研究问题、架构与训练逻辑

> 版本：2026-11-13 / 论文笔记 v0.1。正文基于已保存原文及公开评测；尚未完成代码逐层核验或本地复现。统一记号见[阅读约定](../process/文档维护与阅读约定.md)。

## 研究出发点

作者认为，仅改进encoder而保留简单decoder，可能不能充分利用预训练表示。它将EEG解码改写为具有上下文支持样本的Seq2Seq任务，研究模型能否从当前上下文学习任务映射。

## 从输入到输出的架构

系统包含EEG encoder和序列decoder。

先处理跨数据集的通道对齐与样本长度，再通过encoder将每个EEG片段转换成一段表示。目标样本并不孤立进入decoder：若干支持样本及其标签共同构成context，额外的任务、标签和分隔token表达样本边界和任务信息。

decoder在该序列上作自回归预测，产生目标标签。需要分清三个序列层次：单个EEG内部的时间token、不同支持样本之间的样本位置、符号token位置。它们承载的语义不同。

训练先进行encoder warm-up，再进行contextual training，并逐步增加支持集的规模和多样性。推理时“无参数更新”仍可能利用带标签支持样本；它不是无条件的零信息迁移。

## 训练目标与阶段

必须记录支持集的来源、数量、标签可见性、与目标被试的关系，以及no-support和encoder-only对照。只有在相同信息条件下，才能与REVE的直接分类比较。具体encoder内部卷积层和decoder配置仍需进行代码级核验，本笔记不把当前概念数据流当作逐层复现规格。

## 实验告诉了我们什么

原文有多任务、无支持样本和encoder-only对照；未找到同协议下对REVE的直接结果。

这些结果的协议和具体源表见[评测证据](../benchmarks/评测证据与可比性.md)。整模型优于另一模型，只能支持该完整设置下的比较；模块作用需要相应消融。

## 局限和仍需核对的问题

收益与支持样本来源、数量和标签信息有关。赛事没有授权测试被试标签；支持集只能来自允许的数据范围。

实现核对时重点记录：预处理、实际token形状、位置表示、mask与loss的作用位置、checkpoint版本、可训练模块及读出接口。没有核验到的层数、配置或实现差异不补成确定事实。
