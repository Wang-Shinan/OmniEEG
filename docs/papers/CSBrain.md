# CSBrain：研究问题、架构与训练逻辑

> 版本：2026-11-13 / 论文笔记 v0.1。正文基于已保存原文及公开评测；尚未完成代码逐层核验或本地复现。统一记号见[阅读约定](../process/文档维护与阅读约定.md)。

## 研究出发点

作者将问题定位在尺度上：不同EEG任务依赖的时间跨度、空间范围不同，一次性固定粒度tokenization可能不足。目标是在网络内部反复整合局部多尺度信息，再用结构化的长程交互连接它们。

## 从输入到输出的架构

初始EEG按通道切片，经时域卷积、FFT及谱投影组成初始时频embedding，保留 $C\times N\times D$ 网格。

**CST的时间部分**在每个通道的token时间轴上使用多个卷积尺度，拼接输出并加上对输入的残差投影。其卷积作用于已有token网格，不应直接将论文的kernel=1/3/5解释成原始EEG的1/3/5个采样点。

**CST的空间部分**按导联所属脑区划分局部邻域，在区域内以多尺度空间卷积聚合。时间CST之后接空间CST，形成具有局部多尺度上下文的token。

**SSA的跨窗口attention**将不同时间窗口中具有相同相对位置的token组织成组，在组内计算attention。这提供稀疏的跨窗口信息通路。

**SSA的跨区域attention**从各区域选择代表token，并与区域平均特征组合成descriptor，再进行区域间交互。它通过区域摘要降低全体token直接交互的需求。

CST与SSA交替堆叠。示意模块为

$$H^{l+1}=\operatorname{SSA}(\operatorname{CST}(H^l)).$$

该式省略归一化和残差，只用于说明数据流，不是逐行实现公式。区域划分、代表token采样与通道排序是复现的关键。

## 训练目标与阶段

采用masked autoencoding进行预训练，再对下游任务适配。需要分别检查时域/频域初始编码、多尺度操作和稀疏交互的贡献。作者的区域descriptor消融表明，代表token与区域平均特征的组合优于仅使用其中之一；这是区域聚合设计的证据，不等于移植整个模块到REVE必然获益。

## 实验告诉了我们什么

作者同表比较中，FACED 57.52% 对CBraMod 55.09%；BCIC-IV-2a 56.57% 对51.38%；CHB-MIT则72.62% 低于CBraMod73.98%。本版表中没有REVE。

这些结果的协议和具体源表见[评测证据](../benchmarks/评测证据与可比性.md)。整模型优于另一模型，只能支持该完整设置下的比较；模块作用需要相应消融。

## 局限和仍需核对的问题

跨论文对REVE直接相减无效；区域划分依赖导联语义；结构改善在目标任务和相同训练预算下仍需复现。

实现核对时重点记录：预处理、实际token形状、位置表示、mask与loss的作用位置、checkpoint版本、可训练模块及读出接口。没有核验到的层数、配置或实现差异不补成确定事实。

## 对本项目的启发

只引入多时间尺度和局部/区域交互的思想；先用一个小残差分支验证，不搬入整套CST/SSA。

上述启发是待验证判断。当前研究问题见[REVE改进假设](../research/REVE改进假设.md)，不能把本笔记中的作者模型和我们的改造方案视为同一个模型。
