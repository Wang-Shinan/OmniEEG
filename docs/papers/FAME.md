# FAME：研究问题、架构与训练逻辑

> 版本：2026-11-13 / 论文笔记 v0.1。正文基于已保存原文及公开评测；尚未完成代码逐层核验或本地复现。统一记号见[阅读约定](../process/文档维护与阅读约定.md)。

## 研究出发点

作者关注预训练目标究竟奖励了什么。EEG不同频率的功率相差很大，直接重建时，强功率成分可能主导优化。因此提出把各频段的监督尺度调整到可比范围，检验弱功率频段的信息是否能被更好保留。

## 从输入到输出的架构

输入EEG先分patch、加通道和时间位置表示，并在输入端进行mask；Transformer encoder生成token表示。核心改变在重建目标与输出头。

1. 对原始信号作时频变换，获得随时间变化的谱活动。
2. 将频率划分为若干频段，在每个频段内形成目标 $A_b$。
3. 逐频段标准化：$\widetilde A_b=(A_b-\mu_b)/(\sigma_b+\epsilon)$。
4. decoder从编码表示预测各频段的目标；损失在频段间等权平均。

$$\mathcal L=\frac1{|\mathcal B|}\sum_{b\in\mathcal B}\frac1{|\Omega_b|}\sum_{i\in\Omega_b}(\widehat A_{b,i}-\widetilde A_{b,i})^2.$$

原文实现对完整输出序列施加监督，包含被遮挡与未遮挡位置；mask负责破坏输入，并不意味着损失只计算masked位置。

作者50M与1B版本具有不同宽度、深度和mask比例。下游还涉及表征层选择及token flatten，因此比较时不能只关注预训练损失。

## 训练目标与阶段

原文先在指定下游任务上选择表征层和checkpoint，再用于其它下游评价。其matched MAE对照保持数据、规模和训练配置，输出重建头因目标维度而不同。这比跨模型排行更直接支持目标函数研究。仍应将监督尺度改变、输出目标改变和表征读出三个影响分别分析；对REVE的L1目标不能直接套用MSE的频率加权推导。

## 实验告诉了我们什么

作者独立13任务FT表（Table 7）均分：REVE60.9%、FAME-50M61.4%、FAME-1B60.8%；精神分裂症条目47.2%→67.7%（50M），情绪31.7%→28.6%（50M）。主LP表同样有胜有负。

这些结果的协议和具体源表见[评测证据](../benchmarks/评测证据与可比性.md)。整模型优于另一模型，只能支持该完整设置下的比较；模块作用需要相应消融。

## 局限和仍需核对的问题

该版本41/42/44任务口径不一致；13任务协议写按样本8:1:1，不能自行认定全部被试隔离。频谱相关性不证明REVE失败的原因；REVE用L1，不能直接套用MSE的Parseval论证。

实现核对时重点记录：预处理、实际token形状、位置表示、mask与loss的作用位置、checkpoint版本、可训练模块及读出接口。没有核验到的层数、配置或实现差异不补成确定事实。
